📖 Como jogar Dadinho

O jogo oficial do MemeTrigger!

🎯 Objetivo

Ser o último jogador com dados na mesa. Cada jogador começa com a quantidade de dados definida pelo master. A cada rodada alguém perde um dado; quem fica sem dados vira espectador.

🏠 Sala de espera (lobby)
  • Escolha um apelido e clique em Pronto.
  • O master define: nome, dados por jogador, máximo de jogadores, coringa e se a partida é pública.
  • Todos (menos o master) devem clicar em Ficar pronto.
  • A partida só inicia com 2+ jogadores, todos com apelido e prontos.
🎲 Rolar os dados

Clique em Jogar dados para rolar os seus. Você só vê o resultado dos seus dados; os outros jogadores veem apenas os deles. Quando todos rolarem, começam os turnos.

🗣 Turnos e apostas

Um jogador começa fazendo uma aposta: quantidade de dados + número da face. O próximo deve fazer uma aposta maior ou desconfiar.

Como aumentar a aposta:
  • Quantidade maior que a anterior; ou
  • Mesma quantidade com um número maior.
Coringa (face 1): quando ativo, o 1 vale como qualquer número.
  • Apostar coringa exige quantidade maior que o coringa atual.
  • Voltar de coringa para um número exige o dobro da quantidade.
  • Se alguém apostar 1 no primeiro turno, o coringa é cancelado na rodada.
🕵 Desconfiar

Achou que a aposta anterior é mentira? Desconfie! O jogo conta todos os dados da mesa (coringas contam como o número apostado).

  • Aposta verdadeira: quem apostou vence e o desconfiador perde um dado.
  • Aposta mentirosa: o desconfiador vence e quem apostou perde um dado.
🏆 Vitória

Ao final de cada rodada, a conferência mostra os dados e quem perdeu. O último jogador com dados vence a partida e ganha 1 ponto. Clique em Ok para voltar ao lobby e jogar de novo.

🔒 Verificação dos dados (provably fair) — opcional

Se o master ligar Verificar dados, o resultado deixa de depender do servidor. Antes de qualquer jogador contribuir, o servidor compromete uma entropia externa (um número público do beacon drand); cada jogador gera um número secreto no próprio navegador. A combinação de tudo vira a semente que define os dados e quem começa — ninguém consegue prever ou escolher o resultado.

No fim da partida, tudo é revelado e a auditoria aparece na tela de vitória: qualquer jogador pode conferir, no próprio navegador, que os dados vieram mesmo daquela semente. É um recurso de transparência extra — para jogar normalmente, não precisa mexer nisso.
